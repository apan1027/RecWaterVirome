## Tasks

This optional verification step is excluded from the default workflow.
It uses the same R/community.R functions as 020 to calculate community
results independently from the 012 TSEs and compares them by key with
archived source-project results in legacy-comparison.tsv. Archived
results are comparison inputs, not targets used by the rebuilt
calculations. Run with Rscript scripts/render.R –with-checks, Rscript
scripts/render-step.R 014-legacy-comparison, or the RStudio Render
button. Comparison rules:

- Members, counts, identifiers, taxonomy labels, statuses and
  permutation p values must be identical.
- Deterministic floating-point values are checked for identity first;
  otherwise the tolerance is \|difference\| \<= 1e-12 \* max(1,
  \|archived value\|), accounting for 15 significant digits in TSV files
  and machine-precision summation differences. Larger differences are
  labelled different and require review.
- PCoA comparisons first check distance matrices, then coordinates. A
  whole-axis sign reversal with identical absolute values is labelled
  sign_equivalent.

Neither archived nor rebuilt results are assumed correct merely because
of their age. Differences are documented; the accepted baseline is not
replaced automatically.
