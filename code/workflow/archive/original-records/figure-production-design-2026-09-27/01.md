# 制图设计与验收方案 · design-v2026.09.27.1

本轮只制定方案。沿用故事框架`v2026.09.27.1`，不重跑分析、不制作正式科学图、不初始化或上传代码库。AI复核及最终取舍另见04文件；本文件是Codex裁定的执行规格。

## 1. 从两个参考项目学什么

qproj负责**每一步的输入输出和依赖**，SwDGVirome提供**按论文图阅读代码的方式**。我们采用“一张完整主图一个QMD、一个补图主题一个QMD、共享准备和样式单独管理”。这不是把A/B/C各拆成一个文件，也不是在五个文件中各重复一遍统计。

实际参考范围：SwDG本地`dev_pan`、commit `2c81951e56943b49060d6dcd8326b236e2d82108`；与用户给的GitHub远端一致，未验证实时远端HEAD。完整阅读主图03、补图05/09/11及工具函数、README等；其他部分按记录定向阅读，非全仓全文审计。qproj采用可查源码的已安装0.1.5、RemoteSha `4665814be79e13f7440f26b95279c014e6a5e209`作为实现基线候选，不冒称最新版。详见reference-swdg/source-reviewed.md与reference-qproj/source-reviewed.md。

SwDG并非全图同样式：旧图Times与大画布、新S8的Arial和接近最终尺寸并存。S8另保存绘图值、输入hash和session信息，值得采用。我们不照搬旧字号、未核透明背景、随机无种子的操作、实时注释或不一致的导出对象。

## 2. 全套统一的视觉规格

| 项目 | 工作规格 | 验收方式 |
|---|---|---|
| 尺寸 | 主图宽180 mm，按信息量分别165–220 mm高；是本项目工作尺寸，不是假定某期刊规定 | 读取PDF页面/SVG尺寸，在论文实际放置尺寸复核；不靠整体缩小消除拥挤 |
| 字体 | Arial作为首选；普通文字9 pt、面板字母11 pt加粗、小标题10 pt；关键标签不得低于8 pt | 缺字体时明确报错或声明统一替代字体并整套重绘，不静默混字；检查实际嵌入/替代情况 |
| 线与点 | 起点：主线0.3 mm、样本点约1.6 mm；强调层可适度增加 | 以实际打印尺寸审阅，不把代码参数等同视觉合格；统一处理theme的pt与geom文字的mm |
| 输出 | PDF/SVG作为矢量主文件，白底PNG作预览；栅格预览300 dpi | 正确页面尺寸、无裁切、图层/文字可用；需要位图元素时记录分辨率，不把整图截图塞PDF |
| TIFF | 目标期刊要求时再导出 | 统一白底、尺寸、分辨率和压缩；确保导出的是最终组合图，不是最后一个小面板 |
| 样本顺序 | `bc1, bd1, bc2, gc1, gd1, oc1, od1` | 用固定样本清单，不依字母排序；前者相邻只便于读取同地点标签，bc2单独说明；不伪造处理配对 |
| 地点与标签 | 地点固定颜色：Beijing蓝、Garching橙、Oberschleissheim绿；ID直接标注，c/d用形状或文字辅助 | 建议色值`#0072B2/#E69F00/#009E73`，只表达地点；不将c/d写作已验证处理前后 |
| 其他颜色 | 分类颜色按类别字典冻结；Unclassified灰、Other浅灰且可区分；丰度用顺序色；有正负量才用零中心发散色 | 不跨图交换同一颜色含义；不只靠红绿/颜色识别，灰度与色觉模拟后人工复核 |
| 图注 | 观察句开头，紧接单位、n、必要定义和限制；方法细节引用SI | 与来源表逐项核对；不让图题比结果更强 |

字体、线宽和画布均为待渲染验收的设计值。改字号、色彩、微调布局无需重新会诊；改分母、统计量、筛选阈值或结论必须回到科学审核。

## 3. 五张主图的具体画法

### Figure 1：设计与群落组成，先让读者认识数据

**180×165 mm起稿。** 顶部约30 mm只用一个紧凑设计带：三地点组、七个ID、每份水样的病毒组/16S/18S。下面约105 mm给三组学组成，底部20 mm给完整五级CheckV；不把简单设计拆四块。

优先同序的三个100%堆叠组成面板：病毒按class、16S按phylum、18S按去除Metazoa后的microeuk Division。不同组学是各自相对丰度，不共用绝对生物量解释。病毒保留源表全部8类标签；另两组各取**具名类别在七样本中平均相对丰度最高的8类**，其余具名类别并为Other，未分类单独保留；同分按固定类别名排序。病毒无被合并项时不凭空加Other，无未分类项时不造零值图例。类别数可以不同，样本对齐不要求类别数相同。

这是展示聚合，不改变目录或统计；完整59类别、413行组成保留Data1，另存每个类别归入哪一栏的映射。原始完整组成热图可供核对，不作为第一张主图的默认59行替代品。分类图例置于各自面板附近，不能做59色巨图例。

各组成面板分别标注组学、分类级别与各自相对丰度分母，使用独立分类图例；共用0–100%数值范围不意味着跨组学生物量可比，也不能据图形相似直接断言耦合。

完整度小条标Complete167/High142/Medium450/Low2254/Undetermined47；Low指估计基因组恢复不足50%。该等级和>10 kb长度均不能单独证明reads质量好或坏。全部3060条保留，不新增长度门槛。

### Figure 2：生态信息集中，但不同问题分清

**180×215 mm起稿。** 上排三组学Shannon样本点图约35 mm，中排三个Aitchison PCoA约70 mm，下半部给跨组学摘要与宿主联系，预留标题/图例间隙。

- alpha每组7个点，保留ID。病毒技术稀释重复的SD不画成生物学误差。Shannon与richness不混为一个指标。
- beta直接读取21个已保存坐标，三面板各自等比例坐标；轴解释百分比已是%，不再乘100。不画低n组椭圆、不新增分组拟合。
- 跨组学主图固定三对已有Mantel r，用同一−1至1轴并报告原名义p，不逐对挑最显著检验。Procrustes/RV的完整结果同步放SFig1/配套数据。
- iPHoP显示200条vOTU预测记录的127具名属16S可见、70具名属未检出、3属未解析。CRISPR29条匹配边/13条共检出另列，不共用分母或称感染验证。127为数据集级属可见，不是127种宿主或同样本感染。

正文和图注明确richness–mapped reads ρ=.857（n=7），不冒充Shannon相关；病毒地点的Aitchison p=.725与Bray/Jaccard p=.001/.002不一致，离散度也有限制。图不承担“处理无效”“地理普遍主导”。

方法源代码已定向核对：020病毒以trimmed_tpm、030的16S以counts、040去Metazoa后的18S以counts建立CLR，均指定`pseudocount=1`；060以CLR的欧氏距离形成Aitchison矩阵。080三对Mantel使用Spearman、请求999次置换、块seed=42，p为直接保存的名义值。三份已存Mantel对象的实际方法、999次置换和系数/p与源表一致；上游历史mia版本及CLR逐值重建未验证，不能据当前包实现代替历史运行记录。绘图不重做CLR或检验来填这个来源缺口，详见06定向来源核实（原项目文件`outputs/figure-production-design-2026-09-27/06-会诊后定向来源核实.md`，未复制到本项目）。

### Figure 3：功能图景和具体携带者

**180×215 mm起稿。** 上部约95 mm为7样本×约8–12个KO的热图，右侧对齐同一KO顺序的携带者贡献图；中部约55 mm为工具/定义分开的防御与反防御候选；NARP候选邻域至多占底部约35 mm。

热图值是**携带该KO的vOTU TPM之和**。若用log10(TPM+1)，变换和0值处理写在色标/数据字典；不默认按行Z-score。已有138 KO、68通路全矩阵入Data1，SFig2不强制再画206行大图。旧top20/top30是既有展示结果，不能直接冒充本轮冻结名单。

**本轮已冻结的展示选择：** 按已有矩阵`total_TPM`降序选前10个KO，同分按KO编号排序；另加预先指定的NARP伙伴K13522一行，明确标为案例补充，不冒充top10。共11行：K00558、K13381、K00820、K01939、K00560、K01858、K00390、K13010、K06217、K03462、K13522。详见`F3-display-selection.tsv`及其来源hash；11行的总TPM已与已有driver summary逐行一致核验，未新拟合或新增功能注释。这种按丰度选取只代表主要丰度贡献，不代表所有功能或生物学重要性；完整138行都留Data1。新增名单形成于本轮源表查读，外部面板收到的是其上位原则，未独立评审此11行清单。

右侧采用同KO行序的top1/top2/top3/其余携带者贡献比例，前三位颜色只代表排名，不冒充跨行同一vOTU；主要ID和携带者数直接标，详细对应表保留。名单与逐携带者表对应不上时报告，不由编码模型临时补注释或更换功能。K00558不能凭map00270名字写成硫代谢增强；在本AMG导出表口径中携带者为146，另一全基因注释口径147不得硬套。当前driver表的旧宿主字段不自动作为新宿主结论，需连接已核≥90规则的成员来源。

防御/反防御每个集合注明工具、单位；并集722=106+715−99仅按明确OR规则使用，不把四套工具计数相加。NARP1=3/NARP2=5为DF口径，另一KO共现6条单列。

NARP示意用ORF101–103真实坐标，ORF102标GIY-YIG/NUMOD-like candidate，ORF166不画在该邻域。若压缩AMG主体或无法8 pt呈现，整个邻域面板移SFig2；保留相关阴性结果。不是重新讨论是否值得研究NARP，而是其在本篇的版面职责。

### Figure 4：命中区域与生活史关联

**180×175 mm起稿。** 上部呈现8条有命中的标记序列及必要CheckV边界，下部为区域计数和四模型森林图。

定义表明确三级对象：19条CheckV标记序列，其中8条有20个VF命中；**20个命中**按既有坐标分类互斥计为18 predicted-host、1 boundary-crossing、1 viral。不是18个contig；crossing只计一次。本轮直接核过`vf20_coordinates.tsv`：20行、8个唯一vOTU、20个唯一protein_id、20个唯一(query,target)，现有localization分类确为18/1/1。使用保存分类，不能悄悄换成另一HSP区间规则；连接后必须仍保持唯一键，不能用扩增nrow冒充命中数。完整边界、方向和任何断轴/裁剪要在图内表达。

森林图使用同3013条完整度可用vOTU的四个现有模型，IRR为2.521/1.050/.951/1.003，取已有lo/hi，log IRR轴与1参考线。IRR是生活史类别比较，完整度是已有协变量；四模型均有log(kb) offset。用2×2规则标注区域与标签两个变化维度。这是同数据的一次敏感性分析中的四个依赖估计，不是四次独立重复；不加合并菱形，不按CI是否跨1投票。不能写污染已解释一切或修正证明生物效应为零。

3060→3013的桥梁已逐ID核实：原输入3060条，47条完整度为NA；与原CheckV中`Not-determined`且完整度为NA的47条完全相同（F1显示名Undetermined）。生活史条件没有另排除记录。47条仅从需要完整度协变量的模型中排除，仍在F1目录及F5本地分母中，不能全项目删除。

**180×220 mm起稿。** A约55 mm画本地六档比例；B约55 mm画全球两组完整逐特征系数分布；C约90 mm按两列各19行展示固定38项携带谱系支持，余下留标题间距。

A为有序档、0–100%轴、每档直接标k/n，尤其最高17/18；基因数是回收序列上的预测基因数，无旧拟合/CI/p。B对象为77,951条来源Complete参考序列，285代谢Pfam域与38非NARP profiles，系数单位每10倍CDS增加的log-odds变化。保留全体点、零线、正负值；中位数仅描述选定集合，不画两个平均柱子代替分布。C只筛38而不是整个104行支持表，四单携带簇明确标记。

## 5. 制作前后如何验收

**输入：** 来源路径/版本/hash、列名/单位、样本与特征名单、显示聚合规则冻结。已有生产导出413组成行、6998分类映射、21坐标、38支持和6档比例可用；其他文件已定位不等于本轮生产包已完备。缺口见local-panel-design.md，不将“尚未导出”写成“分析未做”。

**数字：** 核各组成和为1，7样本、3060/3013两个目录、127+70+3=200、18+1+1=20、六档分母和3060/分子和722、285/38固定集合与四单簇。不拿旧130、104或C22/C25替代冻结集合。图里每个数字有源字段。

**版面：** 所有PDF/SVG/PNG逐张全尺寸查看，检查字号、错字、拥挤、裁剪、对齐、坐标比例、图例、色觉、0/NA和透明度；看组合图，不只看独立面板。实际导出尺寸和稿件放置宽度一并记录。字体可选/可嵌入与转轮廓情况如实说明。

**复现：** 无缓存的新R进程按显式依赖顺序render；缺输入失败，不用过期输出顶替。只重绘保存结果与完整原始数据复现分别声明。打包步骤记录生产源hash与复制后hash、接受状态；复制不改变图像内容，不重新拟合。草稿不得冒充验收版。

**状态：** “设计完成”“实现完成”“数值核验通过”“视觉核验通过”分别记录。当前只有设计/来源查读完成，不把文字会诊当作图像通过。

## 6. 统计展示的统一口径

这一节约束标签和图注，不授权新计算。每个面板的源表记录统计量、单位、n、比较集合、原始p/校正p字段及校正方法；没有的字段如实留缺口，不临时补算。

- **F1与F3展示选择：** 组成top8、KO top10+案例补充都是明确的数据依赖展示规则，不称预先盲选，也不作选择后显著性推断。F3标11/138，完整集合可追溯。
- **F2协变与距离：** 三对Mantel固定完整展示，p标为原名义值，不擅称经校正；Procrustes/RV、各距离及离散度的已存结果完整保留。不同距离是同数据的不同表征，不作为独立生物学重复。上游若已有校正结果，保留其原字段和方法，不能统一抹成“从未校正”。
- **F4四模型：** 同3013条、同一生活史效应在四种定义中的敏感性估计，已有95% Wald CI是逐模型区间，不是四模型的同时区间；不用新的多重比较校正代替对定义敏感性的解释。
- **F5特征集合：** 285/38的选择规则与共同参考目录固定；完整系数含负值，不按方向或p筛选。中位数是集合描述，不能推断所有代谢/反防御功能的普遍差异；已有调整、重抽与不可估计结果按原口径进入S4/Data2。本轮不新增检验，也不能误写项目没有做过集合间比较。

这些统计对象不能合并成一个笼统“全篇多重检验族”。实际写Methods/图注时逐项标明，不用一条通用免责声明替代具体方法，也不往每个面板塞重复长句。
