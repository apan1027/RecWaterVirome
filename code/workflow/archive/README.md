# Original evidence archive

Authors (code-document order): Jinlong Ru, Cunli Pan.

This directory preserves historical source-language material. It is not the current code guide. Original review/design documents and the original metadata tables retain their bytes; content-addressed manifest-history files retain both bytes and SHA256 filenames. Original document paths map to the current English archive paths in source-path-map.json (Unicode escapes preserve exact old names).

The current frozen-file register and review register point explicitly to archived report bytes; review dates, verdicts and report hashes are preserved. Updating a current dependency path does not extend a historical review to this revision. Read ../docs/WORKFLOW-GUIDE.md and ../CODE-CHANGELOG.md for the current English workflow description and change scope. Staged raw evidence may also retain its original source language because exact text is used for provenance/value checks.
