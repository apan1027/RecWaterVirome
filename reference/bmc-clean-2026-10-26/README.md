# Final BMC clean reference assets

Authors: Jinlong Ru; Cunli Pan.

These assets are the comparison target copied from the author-selected `BMC_Microbiology_submission_clean_2026-10-26` package. Main TIFFs are in `Figures/`; three workbooks and the structure ZIP are in `Supplementary_Data/`. The four PNGs in `Supplementary_Figures/` were extracted from the clean SI and identified by exact image content. They are code verification references, not extra submission attachments.

Word manuscripts and the cover letter are deliberately not copied into the public-code candidate. Their baseline hashes and the embedded-image identification receipt are in [provenance](../../provenance/bmc-clean-baseline.json). The candidate does not recreate or supersede author edits to Word text.

Reference assets are used for comparison. Reproduction uses the frozen workflow, registered historical publication transforms and the clean consolidation metadata, with added tables checked against independent preserved TSV/JSON inputs.
